# Mnemos VRM idle motions (0.6.7)

Six standing / sway / wait / look / swing loops from the ACCAD Female1 mocap set,
converted to `.vrma` for VRM humanoid playback. These read as feminine standing
idles (soft sway, wait, look-around) rather than generic athletic T-pose clips.
